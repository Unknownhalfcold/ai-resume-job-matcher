# 初学者术语表

## AI 工具

用 AI 帮用户完成某个具体任务的软件。这个项目里的任务是“分析简历和岗位是否匹配”。

## PRD

Product Requirements Document，产品需求文档。

人话版：产品说明书，写清楚这个工具给谁用、解决什么问题、有什么功能。

## MVP

Minimum Viable Product，最小可行产品。

人话版：先做最小的一版，只保留最核心功能，能跑通就行。

## JD

Job Description，岗位描述。

人话版：招聘页面里写的岗位职责、任职要求和加分项。

## Frontend / 前端

用户能看到和点击的部分，比如网页按钮、输入框、结果页面。

## Backend / 后端

用户看不到但负责处理逻辑的部分，比如保存数据、调用 AI、保护 API Key。

## API

Application Programming Interface，应用程序接口。

人话版：一个软件提供给另一个软件使用的入口。比如你的工具通过 API 把文字发给 AI 模型，然后拿回分析结果。

## API Key

调用某个服务时用的密钥。

人话版：像账号密码一样重要，不能公开放在 GitHub 或网页代码里。

## LLM

Large Language Model，大语言模型。

人话版：像 ChatGPT 这样能读懂文字、生成文字、总结和改写内容的 AI。

## Prompt

你给 AI 的指令。

人话版：你怎么问 AI，AI 就大概率怎么回答。好的 Prompt 会让输出更稳定。

## Keyword Matching / 关键词匹配

检查岗位 JD 里的重要词有没有出现在简历里。

人话版：岗位想要 SQL，你简历里有没有 SQL；岗位想要用户研究，你有没有相关经历。

## Weight / 权重

某个因素的重要程度。

人话版：越重要的关键词，影响分数越大。

## GitHub Pages

GitHub 提供的静态网页托管服务。

人话版：可以把你的项目页面免费展示出来，但它不适合直接保存秘密信息，比如 API Key。

## Repository / 仓库

GitHub 上保存项目代码和文档的地方。

人话版：一个项目文件夹的云端版本。
